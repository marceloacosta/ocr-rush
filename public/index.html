YOUR DESIGN

01 Inference GPU capacity

Qwen3.5-4B on L40S · g6e.4xlarge. Frankfurt reference price: about $3.76 per running hour.

02 When do they run?

Scale EKS workers and their EC2 capacity together in this game.

03 Inference request sharing

Share a finite token budget across document streams. This does not combine multiple pages into one prompt.

04 Document storage and recovery

The starting architecture stores documents, results and job state in Redis. These variations let you change where files live and how interrupted work is recovered.

S3 and SQS change the starting architecture: S3 stores files, while SQS adds job acknowledgements and retries. Redis can also support recovery with additional application code.

05 Layout GPU capacity

Render pages on the node’s CPUs and run layout on T4 · g4dn.4xlarge. Reference price: about $1.51/hour. This pool scales separately from inference.

06 Available inference capacity

The starting Terraform configuration permits two inference nodes, while KEDA permits four inference pods. These options explore raising node capacity. AWS quotas and instance availability must also permit the change.

Planning profile · not an AWS benchmark

Startup: 90 s layout / 240 s inference. Idle cooldown: 300 s. Replace these assumptions with measurements before sizing a deployment.
